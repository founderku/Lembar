Buat Hash Password Admin

Halaman ini berjalan sepenuhnya di browser kamu — tidak mengirim apa pun ke internet. Ketik password admin yang kamu inginkan, salin hash yang muncul, lalu tempel ke adminPasswordHash di file config.js pada repo GitHub-mu.

Dipakai apa adanya (huruf besar/kecil dianggap berbeda). Simpan password ini baik-baik — hanya kamu yang tahu.
